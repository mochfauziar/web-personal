Website ini sendiri. Dibangun dengan Next.js App Router, Tailwind CSS v4, dan konten berbasis file MDX yang dikelola lewat Keystatic CMS.

## Fitur

- Blog dengan halaman per tulisan, tag, dan RSS feed
- Halaman proyek dengan konten detail per proyek
- Dark mode otomatis mengikuti preferensi sistem
- OG image di-generate saat build
- Sitemap dan robots.txt dinamis
- CMS berbasis file (Keystatic) — nulis dari browser tanpa push ke Git
